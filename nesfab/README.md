# NESFab executables

Download the [NESFab 1.8 release](https://github.com/pubby/nesfab/releases) and place its executable files in this folder:

- `nesfab.exe`
- `nesfab_legal.exe`

Also download the NESFab source code from the [NESFab GitHub repository](https://github.com/pubby/nesfab) and place it in `source1.8/`.

The executables and `source1.8/` directory are intentionally ignored by Git.
